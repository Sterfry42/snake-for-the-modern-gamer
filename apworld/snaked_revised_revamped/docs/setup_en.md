# Snaked. Revised. Revamped. Setup Guide

Copy `apworld/snaked_revised_revamped` into an Archipelago checkout under
`worlds/snaked_revised_revamped`, or build the `snaked_revised_revamped.apworld` zip with
`npm run build:apworld` (it contains the world folder at its top level).

In the browser game, open the title screen, choose Archipelago, enter the server address and slot
name (plus the room password if the multiworld has one), then connect. The game submits milestone
checks as you play and applies received items, cards, artifacts, and traps automatically.
